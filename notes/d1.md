## PowerShell (mỗi session nếu chưa fix PATH máy)

```powershell
$env:PATH += ";C:\Program Files (x86)\Google\Cloud SDK\google-cloud-sdk\bin"
gcloud auth login
gcloud auth application-default login
gcloud config set project project-6fe3973c-4db8-4b72-83b
```

(2–4 chỉ cần lặp khi hết session / đổi account.)

```powershell

  "PATH",
  $env:PATH + ";C:\Program Files (x86)\Google\Cloud SDK\google-cloud-sdk\bin",
  "Machine"
)
```
